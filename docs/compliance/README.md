# PDPL compliance pack (drafts for legal review)

These documents describe how TrustiqLegal processes personal data for the law firms that use it. They are written from the code as it is today and are **drafts for review by counsel admitted in Oman** before use. Items marked [●] need company details or a decision.

The firm using TrustiqLegal is the **controller** of its clients' data; SmarThinkerz (the operator of TrustiqLegal) is the **processor**. Oman's Personal Data Protection Law (Royal Decree 6/2022) and its Executive Regulation apply, including to processing of Omani residents' data outside Oman since the 2026 amendment. Check the amended text before relying on any summary here.

| Document | Purpose |
| --- | --- |
| [Data processing agreement](dpa-template.md) | Contract terms between the firm (controller) and TrustiqLegal (processor) |
| [Sub-processors](sub-processors.md) | Every service that receives personal data, what it receives and where |
| [Breach response runbook](breach-response-runbook.md) | What happens in the first 72 hours after a suspected breach |
| [Record of processing](record-of-processing.md) | Categories of data, purposes, recipients, retention, security measures |
| [Retention schedule](retention-schedule.md) | How long each kind of data is kept and how it is deleted |

Open decisions for the company:
1. Name a data protection officer and a deputy, with contact details for the DPA and the privacy policy.
2. Choose the hosting location for Omani firms (see the hosting plan); until then, data is processed outside Oman and the transfer basis must be documented.
3. Choose the AI option per firm (zero-retention commercial API, in-region endpoint, or self-hosted model) and record it in the sub-processor list.
4. Confirm the retention periods with counsel and the firms' professional rules.
